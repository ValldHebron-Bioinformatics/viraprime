    Download

    Add sequences on the left. viraprime aligns them, finds primer sites that match every sequence, and picks the best set of overlapping amplicons across the whole genome.

    1. Align. Your sequences are aligned with MAFFT and a consensus is built.
    2. Find primer sites. Every position is tried; primers that fit the Tm, GC and length limits are checked against each sequence, with degenerate bases added where they rescue a strain.
    3. Choose the tiling. Exactly the number of amplicons you asked for, overlapping and split into two pools, picked so the weakest amplicon still covers as many sequences as possible.
