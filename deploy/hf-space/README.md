# viraprime web app

Drop your virus genomes, choose how many amplicons you want, and get overlapping primer
pairs in two pools, each checked against every sequence. Uploaded files are deleted 24 hours
after the job finishes; for private or larger data use the command line.

Source and command line: https://github.com/ValldHebron-Bioinformatics/viraprime
